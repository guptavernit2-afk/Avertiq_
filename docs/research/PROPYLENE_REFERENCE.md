# Propylene reference facts

Source: [NOAA CAMEO propylene datasheet](https://cameochemicals.noaa.gov/report?key=CH4355), reviewed 8 November 2026 (SRC-004).

| Field | Reference value / statement |
|---|---|
| Chemical | Propylene / propene; C3H6 |
| CAS / UN number | 115-07-1 / 1077 |
| Transport state | Liquefied gas under its own vapour pressure |
| LEL / UEL | 2% / 11.1% |
| Relative vapour density | 1.46 at 32 degrees F; air is the reference |
| Boiling point | -53.9 degrees F at 760 mmHg |
| Molecular weight | 42.08; source table does not display a unit |

Retain original conditions and units; do not silently replace them with rounded conversions. These are published reference facts, not measurements of the Adoshi tanker and not a complete thermodynamic property library.

The datasheet identifies ignition, air-displacement and cold-contact hazards. Model-specific property sources may differ and must be reconciled before PHAST/ALOHA comparisons.

The displayed LEL is a concentration in air. A detector reading expressed as percent LEL is a different quantity. Do not confuse the two or choose operational thresholds from this note.

No chemical-response procedure or operational clearance criterion is defined here.
