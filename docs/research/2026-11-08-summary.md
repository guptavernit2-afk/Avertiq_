# First public-data collection: short report

**Status:** research and data collection only. No application code, synthetic sensor readings, physics runs or validated hazard zones.

## Collected

- A sourced incident fact sheet, including conflicting transfer-start times.
- NOAA propylene reference facts with original units and conditions.
- Current OpenStreetMap Adoshi tunnel geometry, retained locally.
- 72 hourly ERA5 weather records for 3-5 February 2026, saved in Git with attribution.
- One Copernicus GLO-30 terrain tile, approximately 45.8 MB, retained locally.
- SMEDIS batch 1 experimental archive, retained locally; integrity checked, experiments not analysed.

## What remains unknown

The exact tanker position, dimensions, pressure, temperature, openings, release-rate history, and actual gas measurements. The tunnel map feature is an approximate geographic anchor, not the accident pin.

ERA5 returned a grid point at 18.75 N, 73.25 E, approximately 10 km from the requested tunnel anchor. It cannot establish local valley wind or tunnel ventilation.
