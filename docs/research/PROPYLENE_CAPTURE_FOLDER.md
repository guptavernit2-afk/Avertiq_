# Four-case capture-folder plan

Planned 15 November 2026 before implementation. This prepares the supervised capture step of [propylene qualification](FIRST_PHYSICS_QUALIFICATION.md) using the existing [frozen cases](PROPYLENE_PREPARATION.md), output-semantics contract and unit-transcription templates. It reduces manual template assembly; it does not run ALOHA or resolve source applicability.

## Scope and acceptance

1. Add one standard-library CLI under research/dispersion that creates a fresh local capture folder for baseline, rate-half, rate-double and wind-higher.
2. Generate `NAME-capture.json` from the existing observation template with unconfirmed output-semantics and raw-unit transcription supplements attached. Observed inputs, run time, engine hash, method, values, warnings/reviews and evidence remain unset/empty. Preserve run_completed=false and all qualification flags=false.
3. Keep frozen case snapshots under a separate inputs directory; never copy intended inputs or expected reference answers into observed fields. Add separate empty evidence directories, a local workflow guide and a setup manifest linking cases and generated file hashes.
4. Validate and serialize the whole package before creating the destination. Refuse any existing destination. Write the manifest last as a completion marker; on a failed write, retain partial files without a completion marker and require a fresh destination. Do not delete/overwrite user material.
5. Test four-case contents and supplements, blank observations, rejection by existing inspectors/normalization, matching case/file hashes, source preservation, existing paths, validation failure, interrupted writes and CLI behaviour. Run full tests and Windows/Linux CI before PR merge.

## Delivery and limits

Plan commit first on codex/propylene-capture-folder, then implementation, tests, PR, diff/CI review and merge. Work is CLI-only. Only disposable test folders will be generated in this task. Actual physics results, model applicability, human evidence review and dashboard physics remain pending. A setup manifest attests initial generated bytes only; manually completed records must pass the existing run/evidence checks separately.
